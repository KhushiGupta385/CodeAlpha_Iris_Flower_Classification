# 🌸 CodeAlpha Task 1 — Iris Flower Classification

> **Data Science Internship Project | CodeAlpha**

## 📌 About the Project

This project is developed as part of my **Data Science Internship at CodeAlpha**.

The objective is to build a Machine Learning model that can classify Iris flowers into three species based on their flower measurements.

**Iris Species:**

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## 📊 Dataset

The project uses the **Iris dataset provided by CodeAlpha**.

| Detail         | Value |
| -------------- | ----: |
| Total Records  |   150 |
| Input Features |     4 |
| Classes        |     3 |
| Missing Values |     0 |

### Features Used

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## 🔎 Project Workflow

**Dataset → Data Analysis → Visualization → Data Preparation → Model Training → Prediction → Evaluation**

### Steps Performed

1. Loaded the Iris dataset.
2. Explored the dataset and checked for missing values.
3. Visualized the flower species and feature relationships.
4. Prepared input features and target labels.
5. Split the data into training and testing sets.
6. Trained a **Logistic Regression** model.
7. Generated predictions on test data.
8. Evaluated the model using:

   * Accuracy
   * Classification Report
   * Confusion Matrix
   * Actual vs Predicted values

## 📈 Model Performance

The Logistic Regression model achieved:

### **96.67% Accuracy** 🎯

The model successfully classified the three Iris flower species with high accuracy.
